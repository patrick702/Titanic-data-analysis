# Titanic-data-analysis
#Project Overview
This project explores survival patterns by class, sex, age and port using Microsoft Excel pivot tables and charts

#Key Insights:
-First class had higher survival than third. 
-Females survived at higher counts than males. 
-Differences by embarkation ports observed. No clear trend by age counts alone. 

#Tools used: Microsoft Excel pivot tables and charts

#File Section:
-Excel workbook included plus chart images

#Skills demonstrated:
-Data cleaning basics, pivot tables, visualization and concise insight writing
